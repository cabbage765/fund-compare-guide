# 十檔基金比較

以原幣、不配息的累積型級別，比較以下 10 檔台灣常見基金：

1. 富蘭克林坦伯頓全球投資系列－穩定月收益基金 美元 A(acc)
2. 施羅德環球基金系列－環球收益成長 美元 A 累積
3. 貝萊德環球資產配置基金 A2 美元
4. 駿利亨德森平衡基金 A2 美元
5. PIMCO 收益增長基金 M 級累積 美元
6. 貝萊德全球智慧數據股票入息基金 A2 美元
7. 元大台灣卓越50 ETF 連結基金 新台幣 A 不配息
8. 元大台灣高股息低波動 ETF 連結基金 新台幣 A 不配息
9. 元大全球優質龍頭平衡基金 新台幣 A 不配息
10. 元大優質收益成長多重資產基金 新台幣 A 不配息

內容包含：

- 1／3／5／10 年年化報酬率、年化波動率、Sharpe Ratio
- 近 3 年與成立以來最大回撤（含高點、低點、回本日期）
- 曆年報酬、淨值走勢、近 3 年水下圖
- 內扣費用、股債比、債券評等、產業分布、國家分布
- 前十大持股重疊與週報酬相關係數矩陣
- 每檔基金的特色與注意事項
- 質押借款試算：加權補倉／平倉維持率、可承受跌幅、虧損情境與組合透視

淨值計算至 2026/10/30，持股與配置取自 2026 年 8–9 月月報。計算方式與資料來源見 `method.html`。
